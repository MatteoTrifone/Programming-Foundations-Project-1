# Programming-Foundations-Project-1

## Tasks and deadlines

The task board is the Excel file [TASKS.xlsx](TASKS.xlsx): one row per task with week, deadline and owner, and a box to tick when it is done.

How to tick a box:

1. Pull, so you have the newest version.
2. Open `TASKS.xlsx` in Excel and tick your box in column A.
3. Save, close Excel, commit and push straight away.

GitHub cannot show or merge Excel files. If two people change the file at the same time, the second push is rejected and that person has to pull and tick again, so keep steps 1 to 3 close together.
